# Detection patterns

Use these with the search tools the user chose. The regexes are written for ripgrep / the Grep
tool, case-insensitive (`-i`) unless noted. Always exclude `.git`, `node_modules`, `vendor`,
`.venv`, `venv`, `dist`, `build`, `target`, `__pycache__`, `*.min.*` and lockfiles.

**Note:** in the tables below, `\|` is only Markdown escaping. Write a plain `|` (alternation) in
the actual regex.

A hit is a **lead**, not a finding. Open the file, confirm what the code actually does, and then
record `path:line`.

---

## 4. Article 5 (prohibited) signals (R02)

These are high-stakes. Report one only after reading the surrounding code and docs.

| Practice | Keywords |
|---|---|
| (a)(b) manipulation / exploiting vulnerabilities | `dark[_-]?pattern`, `subliminal`, `persuasion[_-]?(score\|model)`, `vulnerab(le\|ility)[_-]?(target\|segment)`, `addiction`, `compulsive`, `elderly[_-]?target`, `minor[_-]?target` |
| (c) social scoring | `social[_-]?(score\|credit)`, `citizen[_-]?score`, `trust[_-]?score` (together with behaviour in unrelated contexts), `reputation[_-]?score` together with access to services |
| (d) predicting crime from profiling | `crime[_-]?predict`, `risk[_-]?of[_-]?offend`, `criminal[_-]?propensity` |
| (e) face scraping | `scrap` near `face\|image` and `(instagram\|facebook\|vk\|cctv)`, `face[_-]?database`, `face[_-]?index` built from crawled data |
| (f) emotion recognition at work or school | `emotion` / `sentiment` / `affect` together with `employee\|worker\|staff\|student\|pupil\|classroom\|call[_-]?center[_-]?agent` |
| (g) sensitive biometric categorisation | `(predict\|infer\|classif)` + `(race\|ethnic\|religio\|political\|sexual[_-]?orient\|trade[_-]?union)` together with face, voice or body data |
| (h) real-time remote biometric identification | `real[_-]?time` + `face[_-]?(recogn\|match)` + `(cctv\|camera[_-]?stream\|rtsp)` together with police or public spaces |

- Localisation for EU languages: `locales/(de\|fr\|es\|it\|nl\|pl\|pt\|sv\|da\|fi\|cs\|ro\|hu\|el\|bg\|hr\|sk\|sl\|lt\|lv\|et\|ga\|mt)`, `i18n`
